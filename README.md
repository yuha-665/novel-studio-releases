# ✒️ Novel Studio — 설치 파일

소설 윤문·대필 앱 **Novel Studio**의 설치 파일과 자동 업데이트 정보만 올라오는 곳이에요. (소스 코드는 여기 없어요)

## 설치

1. [최신 버전](https://github.com/yuha-665/novel-studio-releases/releases/latest)에서 `NovelStudio-Setup-<버전>.exe`를 받아요.
2. 브라우저가 **"일반적으로 다운로드되지 않습니다"**라며 막으면 (Edge) 다운로드 목록의 그 파일 옆 **⋯ → 유지**, 이어서 뜨는 창에서 **자세히 표시 → 그래도 계속**을 눌러요.
3. 받은 파일을 실행해서 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 눌러요.
4. 관리자 권한 없이 바로 설치되고, 바탕화면과 시작 메뉴에 바로 가기가 생겨요.

두 경고 다 개인이 만든 앱이라 코드 서명이 없고 아직 받은 사람이 적어서 떠요. 설치 파일은 꼭 이 페이지에서 받아 주세요.

Windows 10/11 (64비트)에서 돌아요.

## 업데이트

- 앱을 켤 때 새 버전이 있는지 한 번 확인하고, 있으면 뒤에서 받아 둬요.
- 위에 **"새 버전을 받아 뒀어요"** 띠가 뜨면 [지금 다시 시작해서 설치]를 누르거나, 그냥 두면 앱을 끌 때 설치돼요.
- ⚙ 설정 → 일반 → **[업데이트 확인]**으로 직접 확인할 수도 있어요.

## 내 데이터는 어디에

| 무엇 | 어디 |
|---|---|
| 원고(작품) · 내 프롬프트 | `문서\Novel Studio` — ⚙ 설정 → 일반에서 바꿀 수 있어요. OneDrive · 구글 드라이브 같은 클라우드 폴더로 두면 여러 PC에서 같이 써요 |
| API 키 · AI 설정 · 사용량 | `%APPDATA%\Novel Studio` — **이 PC에만** 있어요. API 키는 Windows 계정으로 잠가서 저장해요 |

- AI 요청은 내가 고른 곳(Anthropic · OpenAI · Google · OpenRouter · GitHub Copilot · 직접 넣은 주소)으로만 가요. 그 밖에 앱이 인터넷에 묻는 건 업데이트 확인(GitHub)뿐이에요.
- 앱을 지워도 원고와 개인 설정은 남아요.
- API 요금은 각 회사에 직접 내요.

## 이용 조건

- 무료로 쓸 수 있어요.
- 설치 파일을 이 페이지 말고 다른 곳에 올리거나, 앱을 팔거나, 앱을 고치거나 분해해서 퍼뜨리면 안 돼요. 이 페이지 링크를 알려 주는 건 괜찮아요.
- 앱으로 쓴 글은 쓴 사람 거예요. 연재 · 출간 · 판매 어디에 써도 돼요.
- 앱은 있는 그대로 제공돼요 (보증 없음). 원고는 따로 백업해 주세요.
